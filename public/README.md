# Image Placeholders

This directory contains placeholder files for images that should be added to the website.

1. **Hero Images**:
   - `/hero-barber.jpg` - A wide, high-quality image of a premium barber shop interior
   - `/dubai-location-hero.jpg` - Hero image for Dubai location page

2. **Location Images**:
   - `/dubai-barber.jpg` - Image of the Dubai location
   - `/sharjah-barber.jpg` - Image of the Sharjah location
   - `/ajman-barber.jpg` - Image of the Ajman location

3. **Barber Images**:
   - `/barber-ahmed.jpg` - Professional photo of barber Ahmed
   - `/barber-malik.jpg` - Professional photo of barber Malik
   - `/barber-rashed.jpg` - Professional photo of barber Rashed

4. **Other Images**:
   - `/testimonial-avatar.jpg` - Professional headshot of a client
   - `/texture-bg.jpg` - Subtle texture for background overlay
   - `/dubai-map.jpg` - Map showing the Dubai location

## Image Specifications

- Hero image: 1920x1080px (16:9 ratio)
- Location images: 800x1200px (4:3 ratio)
- Testimonial avatar: 400x400px (1:1 ratio)
- Background texture: 500x500px (1:1 ratio, tileable)

## Image Guidelines

- Use high-quality, professional images
- Ensure consistent lighting and style across all location images
- Optimize images for web (compress without significant quality loss)
- Consider the teal/blue color scheme when selecting or editing images
